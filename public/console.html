Slack #ask-ai勉強会 の自動確認（Google Apps Script）

1時間ごとにシステムがチャンネルを読み、「質問・回答した人・✅が付いた回答」を記録します。担当者がスタンプを数える必要はありません。一度設定すれば、あとは自動で動きます。

  1. Slackアプリを作る（社内専用）api.slack.com/apps → Create New App → From scratch。Bot Token Scopes に channels:history channels:read reactions:read users:read users:read.email（未回答のお知らせも使う場合は chat:write）を追加してインストール。
  2. Botをチャンネルに招待#ask-ai勉強会 で /invite @アプリ名
  3. Apps Script を作るGoogleドライブで新しいApps Scriptを作成し、リポジトリの gas/slack-monitor/ の Code.gs と appsscript.json を貼り付け。
  4. スクリプトプロパティを設定SLACK_BOT_TOKEN（xoxb-…）を登録。チャンネルIDとFirebaseプロジェクトは設定済み。
  5. setup を1回実行権限を許可すると、1時間ごとの自動実行が登録されます。このページの「Slack相談の対応状況」に結果が出れば完了。

相談チャンネルのルール（周知用）

  • 質問は #ask-ai勉強会 に投稿する
  • 回答は必ずスレッドで返す
  • 解決したら、質問した人が役に立った回答に ✅ を付ける
  • 回答がない質問は、翌日にシステムがチャンネルへお知らせする（任意設定）
記録されるのは、このチャンネルの投稿だけです。DMやほかのチャンネルは読みません。
